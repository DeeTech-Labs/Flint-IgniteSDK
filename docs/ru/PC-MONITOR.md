# Пример PC Monitor

Скомпилируйте `examples/pc-monitor/project.json` инструментом `tools/compile_ignite.py` из корня SDK и установите бинарный пакет через Ignite Hub. Менять исходники прошивки и прошивать плату не требуется.

Экран объявляет `companion.pc.metrics` с областью `cpu,ram`. Выдайте разрешение в Ignite Hub, запустите компонент и независимо включите политику CPU/RAM во Flare. Отказ, отзыв, отключение и истечение срока образцов показывают недоступное значение, не раскрывая кешированные данные.

Пример не является привилегированным заводским пакетом. [Установка SDK](SDK.md), [модель безопасности](ARCHITECTURE.md), [лицензирование примеров](LICENSING.md).
